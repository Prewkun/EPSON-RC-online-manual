# EPSON RC+ 8.0 Online Manual

Interactive web reference for **Epson RC+ 8.0** — fully self-contained single-file HTML.

## Contents

### ⚡ SPEL+ Language Reference
- 734 commands across 21 categories
- Expandable command cards with syntax, description, and code examples
- Live search + category filter chips
- Cross-linked to GUI Builder entries

### 🎨 GUI Builder Reference
- 17 UI controls (Form, Button, Label, TextBox, LED, Grid, VideoBox, etc.)
- 87 properties, 9 events, 5 SPEL+ statements (GClose, GGet, GSet, GShow, GShowDialog)
- Bidirectional cross-links → click any badge to jump between SPEL+ ↔ GUI

### 📘 RC+ Users Guide
- 23 chapters covering the full RC+ 8.0 development environment (742 pages)
- Structured into 10 topic groups: Getting Started, The RC+ IDE, SPEL+ Development, Simulator, Hardware & I/O, Connectivity, Security, Advanced Features, Calibration, Options
- Chapter 5 (RC+ IDE) includes detailed subsections for all menus: File, Edit, View, Project, Run, Tools, Setup, Window
- Chapter 6 (SPEL+ Language) and Chapter 7 (Building Applications) include subsections covering key development concepts
- Live search across all chapters + filter chips by topic group

## Usage

Open `index.html` in any modern browser. No server or internet connection required.
